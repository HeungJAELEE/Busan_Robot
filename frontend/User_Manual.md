# 🐵 완전 기초부터 알려주는 Indy7 Command Center 조작 매뉴얼

이 매뉴얼은 화면에 보이는 "모든 버튼과 글자"가 무슨 역할을 하는지 하나도 빠짐없이 설명합니다. 기계를 전혀 모르는 분도 이 설명서만 읽고 순서대로 누르면 로봇을 다룰 수 있습니다!

---

## 🌎 0. 항상 떠있는 공통 버튼 (화면 맨 위 / 맨 왼쪽)
어떤 페이지에 있든 항상 누를 수 있는 고정 버튼들입니다.

* **[로봇 통신 연결] (우측 상단 초록색 버튼)**
  * **기능**: 이 버튼을 눌러야 PC와 실제 로봇이 전파로 연결됩니다. 가장 먼저 눌러야 하는 1순위 버튼입니다.
* **[Page 1] Auto / Monitor Mode (상단 탭)**
  * **기능**: 로봇이 움직이는 모습을 3D 화면으로 구경하고 감시하는 "모니터링 화면"으로 이동합니다.
* **[Page 2] Setting / Teaching Mode (상단 탭)**
  * **기능**: 로봇에게 일을 가르치고(티칭), 네트워크를 설정하고, 프로그램을 짜는 "작업 화면"으로 이동합니다.
* **로봇 선택 (Robot A) 드롭다운 메뉴 (좌측 상단)**
  * **기능**: 현재 내가 명령을 내릴 로봇을 고릅니다. (Robot A, B, C 중 선택)
* **[Home 위치] (파란색 버튼)**
  * **기능**: 로봇을 기본 대기 자세(집)로 안전하게 되돌려 놓습니다.
* **[Zero 위치] (주황색 버튼)**
  * **기능**: 로봇의 모든 관절을 일자로 꼿꼿하게 폅니다.
* **[에러 리셋] (보라색 버튼)**
  * **기능**: 로봇이 벽에 부딪히거나 빨간불이 들어오며 멈췄을 때, 에러를 지우고 다시 정상 상태로 만듭니다.
* **[비상정지 (E-STOP)] (빨간색 버튼)**
  * **기능**: 위험한 상황일 때 누르면 로봇이 즉시 그 자리에서 굳어버립니다!

---

## 🖥 1. [Page 1] Auto / Monitor Mode 화면

로봇이 일하는 걸 구경하는 화면입니다.

* **3D DIGITAL TWIN VIEWER (가운데 큰 검은 창)**
  * **기능**: 현실에 있는 로봇의 움직임을 컴퓨터 그래픽(3D)으로 똑같이 보여줍니다.
  * **위험 가이드 색상**: 궤적 점과 TCP 테두리가 초록이면 권장 안전, 주황이면 감속/확인 권장, 빨강이면 회피 또는 분리 테스트 권장입니다.
  * **투명 존 표시**: Robot A/B/C 간격 185cm, 로봇 전면 rail 거리 50cm, 공통 Place 감시 구역이 투명 박스로 표시됩니다. 이 박스는 실제 JSON 좌표를 바꾸지 않는 안내 표시입니다.
* **로봇 연결 대기중 (하단 초록색/회색 네모)**
  * **기능**: 로봇 A, B, C가 현재 켜져 있는지 꺼져 있는지 불빛으로 알려줍니다.
* **TELEMETRY DATA (우측 상태창)**
  * **기능**: 현재 로봇의 머리끝 좌표(TCP)와 6개 관절 각도를 숫자로 실시간 표시해 줍니다.

## 🛠 2. [Page 2] Setting / Teaching Mode 화면

여기가 진짜 로봇에게 일을 시키는 공간입니다. 이 페이지에 들어오면 아래에 4개의 "하위 메뉴"가 생깁니다. (`옵션`, `로봇설정`, `프로그램`, `로그`)

### 📌 2-1. 하위 메뉴: [옵션] (System Options & I/O Monitoring)
로봇의 센서(눈/귀)와 손(그리퍼)을 설정하는 곳입니다.

* **Digital Input (D.I)**
  * **기능**: 외부 센서(예: 물건이 들어왔다!) 신호가 켜졌는지 00~15번까지 확인합니다.
* **Digital Output (D.O)**
  * **기능**: 로봇이 외부로 보내는 신호(예: 컨베이어 벨트 돌아가라!)를 켭니다. 버튼을 직접 눌러서 신호를 껐다 켤 수 있습니다.
* **TCP Settings (가운데 창)**
  * **기능**: 로봇 팔 끝에 매달린 '도구(그리퍼)'의 길이나 무게중심을 입력합니다. (보통 전문가가 한 번 세팅하면 안 건드려도 됩니다.)
  * **[TCP 로봇 적용]**: 입력한 숫자를 로봇에 진짜로 반영합니다.
* **Tool / Gripper Settings (우측 창)**
  * **Gripper / Suction (흡착) 버튼**: 로봇 손이 '집게'인지 '뽁뽁이'인지 고릅니다.
  * **Grip DO Pin / Release DO Pin / Sensor DI Pin**: 그리퍼를 쥐고 펼 때 쓸 전기선 번호를 적어줍니다.
  * **[테스트 Grip / Hold] / [테스트 Release]**: 전기선 연결이 잘 됐는지 테스트로 직접 집게를 오므리고 펴볼 수 있습니다.
  * **[툴 매핑 저장]**: 설정한 내용을 저장합니다.

---

### 📌 2-2. 하위 메뉴: [로봇설정] (NETWORK & IP CONFIG)
와이파이 잡듯이 로봇의 주소(IP)를 맞추는 곳입니다.

* **로봇 IP / PLC IP (숫자 적는 곳)**
  * **기능**: 로봇의 고유 주소(예: `192.168.3.7`)를 적어줍니다.
* **[PLC 연결] / [로봇 연결] / [저장]**
  * **기능**: 적어놓은 주소로 통신을 뚫어보고, 성공하면 설정값을 [저장]합니다.

---

### 📌 2-3. 하위 메뉴: [프로그램] (가장 중요한 티칭 공간 ⭐️)
물건을 옮기는 순서를 짜는 메인 화면입니다. 좌측, 중앙, 우측 3개 구역으로 나뉩니다.

**[좌측 구역 - 명령어 버튼들 (COMMANDS) 완벽 사용법]**
작업 순서(트리)에 새로운 지시사항을 추가할 때 누르는 버튼들입니다. 트리에 추가된 블록을 클릭하면, 우측 상단 **[사용자 설정]** 창에 아래와 같은 입력칸들이 나타납니다.

* **[+ Folder] (주황색 - 폴더)**
  * **어떻게 쓰나요?**: 우측 설정창에서 `폴더 이름`을 적어줍니다. (예: "박스 집기 과정"). 그리고 다른 동작 블록들을 마우스로 드래그해서 이 폴더 아래로 쏙 밀어 넣으면 깔끔하게 정리됩니다.
* **[+ Move Home] (파란색 - 대기 자세)**
  * **어떻게 쓰나요?**: 이 블록은 추가만 하면 끝입니다! 아무 값도 입력할 필요 없이 로봇이 알아서 기본 대기 자세로 돌아갑니다.
* **[+ Move J] (파란색 - 관절 부드럽게 이동)**
  * **어떻게 쓰나요?**: 우측 설정창에서 아래 3가지를 합니다.
    1. 조종기로 로봇을 목적지로 이동시킨 후 **[위치 업데이트]** 버튼 클릭! (좌표 도장 쾅)
    2. `속도(%)`: 1~100 사이 숫자를 넣습니다. (보통 20~50)
    3. `가속도(%)`: 출발할 때 얼마나 확 튀어나갈지 정합니다. (마찬가지로 20~50)
* **[+ Move L] (초록색 - 직선 반듯하게 이동)**
  * **어떻게 쓰나요?**: Move J와 똑같이 **[위치 업데이트]**를 누른 뒤, `속도`와 `가속도`를 입력합니다. (좁은 구멍에 넣을 때 필수)
* **[+ Move B] (주황색 - 모서리 부드럽게 넘어가기)**
  * **어떻게 쓰나요?**: 우측 설정창에 `블렌딩 반경(Radius)`이라는 칸이 생깁니다. 여기에 `50` (50mm)이라고 적어주면, 로봇이 목적지에 도착하기 5cm 전부터 브레이크를 밟지 않고 다음 목적지로 둥글게 스무스하게 꺾어 들어갑니다.
* **[+ Move By] (보라색 - 현재 위치에서 찔끔 이동)**
  * **어떻게 쓰나요?**: 우측 설정창에 `X, Y, Z` 입력칸이 나옵니다. 만약 "지금 위치에서 위로 10cm만 올라가라!" 하고 싶으면, `Z` 칸에만 `100` (100mm)을 적어줍니다.
* **[+ Move C] (청록색 - 원 그리기)**
  * **어떻게 쓰나요?**: 점 3개가 필요합니다. 시작점(P1)은 이전 블록 위치이고, 이 블록에서 **[경유지(P2) 위치 업데이트]** 와 **[도착지(P3) 위치 업데이트]** 버튼을 두 번 눌러서 둥근 원호를 그려줍니다.
* **[+ Force] (갈색 - 힘 조절)**
  * **어떻게 쓰나요?**: `Z축 누르는 힘(N)` 칸에 `10` (약 1kg) 같은 숫자를 넣습니다. 로봇이 바닥으로 내려가다가 이 힘을 받으면 부서지지 않게 딱 멈춥니다.
* **[+ Set DO] (보라색 - 전기 신호 내보내기)**
  * **어떻게 쓰나요?**: 우측 설정창에서 `핀 번호(Pin No.)`에 내보낼 선 번호(예: `1`)를 적고, `상태(Value)`를 **1(켜기)** 또는 **0(끄기)** 중에 선택합니다. (예: 1번 컨베이어 켜!)
* **[+ Set AO] (연두색 - 아날로그 신호 내보내기)**
  * **어떻게 쓰나요?**: `핀 번호`를 적고, 이번엔 0/1이 아니라 **0~10V 사이의 소수점 숫자**(예: `5.5`)를 입력해서 섬세하게 제어합니다.
* **[+ Wait] (회색 - 무조건 기다리기)**
  * **어떻게 쓰나요?**: 우측 설정창 `대기 시간(초)` 칸에 `3` 이라고 적어주면 무조건 3초 멈춰있다가 다음 블록으로 넘어갑니다.
* **[+ Wait DI] (남색 - 외부 신호 올 때까지 기다리기)**
  * **어떻게 쓰나요?**: `핀 번호`에 센서선 번호(예: `2`)를 적고, `상태`를 **1**로 두면 "2번 센서에 물건이 닿아서 1(ON)이 될 때까지 무한정 기다려라"가 됩니다.
* **[+ Wait AI] (회색 - 아날로그 신호 올 때까지 기다리기)**
  * **어떻게 쓰나요?**: `핀 번호`를 적고, `비교 조건(>, <, =)`과 `기준값(V)`을 적습니다. (예: 1번 핀 온도가 5V보다 `>` 커질 때까지 기다려라)
* **[+ Loop] (빨간색 - 반복하기)**
  * **어떻게 쓰나요?**: `반복 횟수(Count)` 칸에 `10`이라고 적고, 반복할 동작들을 마우스로 드래그해서 이 Loop 블록 아래로 종속되게 밀어 넣습니다.
* **[+ Switch] / [+ If (DI)] (분홍색/자주색 - 만약에~ 라면 갈림길)**
  * **어떻게 쓰나요?**: `조건(DI 핀 번호 등)`을 설정합니다. 조건이 맞을 때 실행할 블록들은 이 블록 아래로 드래그해서 넣어줍니다. 맞으면 안의 내용을 실행하고, 틀리면 건너뛰고 다음 블록으로 갑니다.
* **[+ Math] (주황색 - 변수 계산)**
  * **어떻게 쓰나요?**: 우측 설정창에서 `변수 이름(예: COUNT)`, `연산자(+, -, *, /)`, `더할 값(예: 1)`을 적어주면 이 블록을 지나갈 때마다 COUNT가 1씩 늘어납니다.
* **[+ Vision] (하늘색 - 카메라 연동)**
  * **어떻게 쓰나요?**: 우측 설정창에서 카메라 이름/IP를 선택하고, 물건을 찾으면 사진을 찰칵 찍어서 그 위치로 로봇을 보정시키는 세팅을 합니다. (고급 기능)
* **[+ Sync] (노란색 - 다른 장비와 동작 맞추기)**
  * **어떻게 쓰나요?**: `동기화 아이디(Sync ID)` 칸에 예를 들어 `100`을 적으면, 옆 로봇도 `100`이라는 Sync 번호에 도달할 때까지 서로 기다렸다가 "하나 둘 셋!" 하고 동시에 출발합니다.
* **[+ Pick] / [+ Place] (청록색 - 팔레타이징 포함 핵심 동작)**
  * **어떻게 쓰나요?**: 우측 상단에서 **[단일 위치]** 탭인지 **[팔레타이징]** 탭인지 고릅니다.
  * **단일 위치일 경우**: 로봇을 옮긴 뒤 **[위치 업데이트]** -> 끝!
  * **팔레타이징일 경우**: 로봇을 첫 물건에 두고 **[Get]** -> `크기(Ix,Iy,Iz)`와 `간격(Gx,Gy)` 숫자 입력 -> `배열(M, N)`과 `층수(L)` 숫자 입력 -> **[⚡ 자동 계산]** 누르기 -> 끝!
  * **공통 필수값 설정**: 아래쪽 `접근(App)/후퇴(Ret) 거리` 칸에 `50` (50mm)이라고 적어주면 허공 5cm 위에서 살포시 멈췄다가 내려가는 섬세한 동작이 완성됩니다.

**[중앙 구역 - 프로그램 트리]**
* **[불러오기] / [저장]**: 이전에 짰던 작업 순서 파일(JSON)을 불러오고, 수정한 뒤 다시 저장합니다. 태블릿 앱과 호환됩니다!
* **Main Program (검은 배경의 글씨들)**: 좌측에서 추가한 블록들이 여기에 시간 순서대로 위에서 아래로 주르륵 쌓입니다.
* **[▶ Play (가상)]**: 짜놓은 순서대로 3D 화면에서 경로를 미리 봅니다. DI 버튼을 미리 켜면 조건문과 Loop가 실제 순서처럼 펼쳐집니다.
* **3D 화면의 투명 박스**: rail, Place 하강 감시, 로봇 간 작업영역 겹침을 보여줍니다. 빨간/주황 박스가 보이면 실제 실행 전에 속도를 낮추거나 구간 분리 테스트를 먼저 합니다.

**[우측 구역 - JOG 컨트롤러 (조종기)]**
이 구역은 로봇을 내 손으로 조종하는 곳입니다.
* **조인트(Joint) / 서버(Base) / 툴(TCP)**
  * **조인트**: J1~J6까지 관절 하나하나를 꺾을 때 씁니다.
  * **서버(Base)**: 로봇 바닥 기준으로 앞뒤좌우 반듯하게 움직일 때 씁니다.
  * **툴(TCP)**: 로봇 손목 끝이 바라보는 방향 기준으로 움직입니다.
* **[-] / [+] 버튼**: 마우스로 꾹 누르고 있는 동안 로봇이 지잉~ 하고 움직입니다.
* **속도 조절 슬라이더**: 처음엔 무조건 왼쪽(느림)으로 두세요! 우측으로 갈수록 무섭게 빨라집니다.
* **[▶ 로봇 이동] (초록 버튼)**: 트리에서 선택한 목적지 좌표로 로봇을 자동으로 한 번에 훅 보냅니다. (주의!)

**[우측 구역 - 사용자 설정 (상세 에디터)]**
트리에서 노드를 클릭하면 그 노드에 맞는 설정창이 우측 JOG 위에 나타납니다.
(예: **Pick 노드**를 클릭했을 때!)
* **단일 위치 / 팔레타이징 / 비전 (버튼 3개)**: 물건을 1개만 집을 건지, 박스를 층층이 쌓을 건지 고릅니다.
* **[위치 업데이트]**: JOG로 로봇을 이리저리 옮긴 다음, "지금 이 자리를 기억해라!" 하고 도장을 찍는 버튼입니다.
* **[조그로 불러오기]**: 반대로, 이전에 도장 찍어둔 위치를 JOG 컨트롤러 패널에 숫자로 불러옵니다.
* **[1. 투입위치(App) / 2. 정위치(Target) / 3. 배출위치(Ret)]**
  * 로봇이 물건 위 대기장소(1)에 갔다가 -> 내려가서 집고(2) -> 다시 위로 빠져나오는(3) 세 가지 위치를 각각 이동해 보는 버튼입니다.
* **[3동작 자동 실행]**: 위 3단계를 한 번에 연속으로 부드럽게 테스트해 줍니다.
* **(스크롤을 아래로 내리면 나오는) 3단계. 팔레트 패턴 설정**
  * **[Get]**: P1(첫 물건 위치)에 조종기로 로봇을 갖다 대고 이 버튼을 누르면 숫자가 쏙 들어갑니다.
  * **크기(Ix,Iy,Iz) / 간격(Gx,Gy)**: 상자 하나 크기와 상자 사이 빈틈을 밀리미터(mm)로 적습니다.
  * **배열 M, N, 층수 L**: 가로로 몇 줄, 세로로 몇 줄, 위로 몇 층 쌓을지 적습니다.
  * **[⚡ 자동 계산]**: 이 번개 모양 버튼을 누르면, 나머지 P2, P3, P4 끝점 좌표를 컴퓨터가 완벽하게 다 알아서 계산해 줍니다. (절대 직접 계산하지 마세요!)

## 📊 3. [Page 3] Dry Run Recording 화면

실제 생산 전에 프로그램을 반복 실행하면서 로봇의 관절각, TCP 좌표, 토크, 상태를 기록하는 화면입니다.

* **목표 반복**
  * **기능**: 몇 회 반복 기록할지 정합니다. 예를 들어 `100`을 넣으면 프로그램이 완전히 끝나는 것을 100회 카운트합니다.
* **샘플(ms)**
  * **기능**: 실시간 데이터를 몇 ms마다 저장할지 정합니다. 기본은 100ms입니다.
* **가상 DI 입력**
  * **기능**: 실제 외부 센서 대신 DI 0~31을 화면에서 미리 켜고 끕니다. Robot A의 예시는 DI10이 대기 게이트이고 DI11/12/13이 Red/Blue/Green 선택입니다.
* **로컬 JSONL 저장**
  * **기능**: PC 폴더에 `metadata.json`, `samples.jsonl`, `events.jsonl`, `summary.json`을 저장합니다.
* **MySQL 실시간 기록**
  * **기능**: MySQL DB에 session, event, sample을 저장합니다. DB 연결 확인이 성공한 뒤 켭니다.
* **시작 / 정지**
  * **기능**: 선택한 Robot A/B/C의 프로그램을 Dry Run Recording 조건으로 실행하거나 멈춥니다.

중요한 안전 규칙:

```text
collision=1, error=1, status_read_failed가 나오면 즉시 정지합니다.
에러 리셋 후 Home으로 돌아간 뒤 로그를 보고 다음 테스트를 정합니다.
충돌 상태에서 반복 횟수를 계속 밀어넣지 않습니다.
```
